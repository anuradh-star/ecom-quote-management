# ecom-quote-management
My Quote Management Project 

How to run:
System used During Development : 
-	Intellij community edition
-	Maven 3.4
-	Java 21
-	Postgres database
Review application properties file and update details based on your system ( default value already there)
Import ecommerce_db_v2 in postgres database to have some initial database for sample run.
Run mvn clean install to generate jar
Run spring project 
Open http://localhost:8080/ ( port is coming from application properties file)
